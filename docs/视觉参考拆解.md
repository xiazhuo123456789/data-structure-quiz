# 撕卡 / 盲盒抽卡视频拆解

参考链接：

1. https://v.douyin.com/9rqLzu-GGMY/
2. https://v.douyin.com/KQa-tWCWcBI/
3. https://v.douyin.com/0NNZHzjldrw/

三条视频里能看到两套很近的视觉系统：浅色舞台的 `holo` 封套，和深色走廊的 `SimpleMkt / PRISM` 盲盒。它们都不是“点一下弹出结果”，而是把“拆开”本身做成主要内容。

## 一、浅色 holo：把卡包做成一个角色

观察到的画面：

- 1.7 秒：五张角色卡呈扇形摊开，角色是 Blip、Ringo、Cubit、Facet、Nova。每张卡都有独立配色、角色名、编号和小图标。
- 9.6 秒：回到单包状态。浅灰米白背景，正中央一包洋红色 `holo` 卡包，底部只有很小的 \"Open another pack\"。
- 11.5 秒：包装顶部的封条被掀起，星形角色表情变成“><”，像被撕疼了。
- 13.5 秒：封条继续拉开，裂口处喷出彩虹色纸屑。
- 15.5 秒：五张卡再次扇形摊开，卡包退到画面之外。
- 17.9 秒：卡包换成蓝色版本，说明同一套包装可以换色复用。

可复用的关系：

- **一个物体占舞台中心**。没有多余面板，品牌在顶部，进度和操作在底部，视线只跟着卡包走。
- **包装有表情**。星形角色不是贴纸，它会看、会疼、会眯眼。撕到一半时的表情变化，比完整打开更有传播点。
- **撕裂有阻力**。封条不是按钮，拖动距离决定裂口深度；松手不过半会回弹。这个“没撕开”的状态本身也是内容。
- **奖励是扇形展开**。不是列表，也不是网格，而是像手里捏着五张卡。第一张在前，其余在后，保留“刚拆出来”的现场感。
- **卡片信息分层**。角色图最大，名字第二，编号和稀有度最小。高光、渐变和纸屑都不会压住文字。

## 二、深色 SimpleMkt：盲盒靠“没集齐”驱动

观察到的画面：

- 深色走廊，左右是密集的竖向细线，中间一束顶光。顶部只有 `SimpleMkt`，底部是 `0/17 · 1/7 PACKS` 和 `AUTO` 开关。
- 正中央一包紫色 `PRISM`，包装上有一个带脸的四角星。
- 打开后出现五张卡，其中三张是未解锁的 `?`，两张是小猫角色。已解锁的卡有名字、稀有度和编号。
- 后面出现收藏册：`12/18`，网格里亮着的猫卡和暗着的未收集卡并排。
- 结尾把五张卡放大，出现 `SECRET RARE`、`MYTHIC` 等稀有度标签，再给 `PULL AGAIN`。

可复用的关系：

- **先给一部分，不一次给完**。五张卡里只亮两张，剩下三张是 `?`。未收集的空位会让人想再开一包。
- **收藏册是第二舞台**。抽卡结束后不是回到首页，而是把新卡放进一个更大的收集网格里，告诉用户“你还差几张”。
- **稀有度是视觉标签，不是数值**。颜色边框、角标和小字承担稀有度，不需要额外解释。
- **深色舞台让卡片自己发光**。背景接近黑，卡片的高饱和色和细边框成为唯一亮点。

## 三、两条视频共同的节奏

1. **封住**：只看到包装、品牌、进度。用户知道里面有东西，但看不到。
2. **试探**：鼠标或手指碰到封条，包装先有轻微形变，角色有反应。
3. **破坏**：封条掀起，裂口出现，纸屑或彩虹边从缝里出来。
4. **揭晓**：一张张卡展开，先看角色，再看名字，最后看稀有度。
5. **再开**：底部只留一个很轻的入口，`Open another pack` 或 `PULL AGAIN`，不打断节奏。

## 四、放进答题应用时，保留什么

保留：

- **单物体舞台**：首页中央是一包“封好的题卡”，不是统计面板堆叠。
- **真实阻力**：作业模式提交后，答案被不透明封条盖住；向下拖动才揭开，松手不过半会回弹。
- **包装有反应**：封条被拖动时，封面上的四角星和提示文字跟着移动；完全撕开后有短促的纸屑爆发。
- **声音参与**：用 Web Audio 合成很轻的纸张摩擦声，不依赖外部音频文件。
- **揭晓后再读**：封条下面才是浅色答案纸，保证长解析的阅读舒适度。

不照搬：

- **不做抽卡概率和稀有度**。这是学习工具，答案不该变成“抽到 SSR”。
- **不做无限再开一包**。答题的“收集”应该是错题本和章节进度，而不是盲盒。
- **不把文字压在高光上**。参考视频里最值得学的是“效果再花，信息仍然清楚”。

## 五、本次落地的对应关系

| 参考里的做法 | 答题应用里的实现 |
| --- | --- |
| 浅色/深色舞台中央放一个封套 | 首页深色展台，中央放 `CHAPTER 01—05` 题卡包 |
| 包装有脸、会对撕扯做表情 | 封条中央放四角星徽记，拖动时徽记和提示一起下移 |
| 拖动距离映射撕裂深度 | `--peel` 变量控制 `clip-path`，拖动越深，答案露出越多 |
| 松手不过半回弹 | 松手进度小于 54% 时弹回 0，超过才完成 |
| 裂口出现纸屑 | 四角星周围 12 片彩色纸屑爆发 |
| 底部只留轻量再开入口 | 撕开后只保留“下一题”，不额外堆操作 |
| 奖励扇形展开 | 题卡和解析保持单张阅读，不摊成多卡 |
